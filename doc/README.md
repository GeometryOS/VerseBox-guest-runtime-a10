# Android 10 Runtime Documentation

This documentation belongs to the standalone A10 guest-runtime repository. It covers A10 source builds, ROM packaging, and this repository's own GitHub Actions release. The VerseBox CE app repository consumes published ROM artifacts but is not part of this repository's Gradle build graph.

## Sections

| Directory | Scope |
| --- | --- |
| [RELEASE](RELEASE/README.md) | A10 artifact layout, release pipeline, version metadata, and verification |

The A9, A10, and A15 guest runtimes remain separate source repositories. Do not use the app repository's CI as evidence that this runtime can be rebuilt.
