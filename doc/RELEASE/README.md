# A10 Release

This section documents the A10 repository's own release pipeline. Release assets are generated by the checked-out A10 source and gated by the A10 GitHub Actions workflow.

## Reading order

| File | Scope |
| --- | --- |
| [FLOW/01-RELEASE-PIPELINE.md](FLOW/01-RELEASE-PIPELINE.md) | CI and tag release flow |
| [FLOW/02-ARTIFACTS.md](FLOW/02-ARTIFACTS.md) | ROM version directory and generated audit intent |
| [FLOW/03-VERSION-SOURCES.md](FLOW/03-VERSION-SOURCES.md) | Source of version pointer and app compatibility floor |
| [FLOW/04-VERIFICATION.md](FLOW/04-VERIFICATION.md) | Unit tests, ROM checks, hashes, and release gates |

The generated pack-audit-intent.json is an output. Never author or commit a hand-written copy.
